## Convención de nombres de archivos

Todos los archivos deberán nombrarse utilizando la inicial del nombre y el apellido de los integrantes del grupo.

### Formato requerido

```text
TP_IS_JPEREZ_AGOMEZ.ZIP
```

### Ejemplo

- `J` → Juan Pérez
- `A` → Ana Gómez

Resultado:

```text
TP_IS_JPEREZ_AGOMEZ.ZIP
```
